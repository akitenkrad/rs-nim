# 遊び方

## ルール

盤面にはいくつかの石の山があります．2 人が交互に手番を持ち，自分の番では山を **1 つ** 選んで，そこから石を **1 個以上** 取ります．

| ルール | 勝者 |
|---|---|
| 通常 | 最後の 1 個を取った方が勝ち |
| ミゼール | 最後の 1 個を取った方が **負け** |

## 対局の開始

`rs-nim`（または `cargo run --release`）を実行するとタイトル画面が開きます．設定を変えてから `Enter` / `Space` で開始します．

| キー | 設定 | 値 |
|---|---|---|
| `d` | 難易度 | やさしい / ふつう / 最強 |
| `r` | ルール | 通常 / ミゼール |
| `f` | 先手 | あなた / CPU |
| `p` | 山の配置 | ランダム（1〜9 個の山を 3〜5 個）/ 1-3-5-7（古典） |
| `l` | 言語 | English / 日本語 |

CPU は必勝手（[必勝法](strategy.ja.md) を参照）を，難易度に応じた確率で選びます．やさしい 20 %，ふつう 65 %，最強 100 % です．必勝手が無い局面では，最強は最大の山から 1 個だけ取って相手のミスを待ち，それ以外の難易度は合法手をランダムに指します．

## 対局中の操作

| キー | 動作 |
|---|---|
| `←` `→` / `Tab` | 山を選ぶ |
| `↑` `↓` / `1`-`9` | 取る個数 |
| `Enter` / `Space` | 選んだ石を取る |
| `h` | ヒント: 必勝手を表示（必敗局面ならその旨を表示） |
| `b` | ニム和パネルの表示切替 |
| `s` | 現在の対局を棋譜ファイルに保存（[リプレイ](replay.ja.md) を参照） |
| `n` | 新しい対局 |
| `t` / `Esc` | タイトルへ |
| `q` / `Ctrl-C` | 終了 |

取る予定の石は確定前に強調表示されます．取った石は浮かび上がりながら細く暗くなって消えます．勝つと紙吹雪，負けると雨が降ります．

## ニム和パネル

`b` を押すと，各山の 2 進数とその XOR（**ニム和**）を表示します．1 が奇数個ある桁は強調されます．相手に必敗局面を渡すには，まさにその桁をそろえればよいからです．理由は [必勝法](strategy.ja.md) を参照してください．

## 表示言語

画面の表示は既定で英語です．タイトル画面で `l` を押すか，`--lang ja` を付けて起動すると日本語になります（`replay` でも使えます）．

## 端末の要件

- **90 × 26** 以上の端末サイズが必要です．
- True Color（24bit）対応の端末を推奨します．WezTerm，iTerm2，kitty，Alacritty など．
- 石は背景色付きのセルで描くので，特別なフォントは要りません．
- 日本語環境で罫線や矢印の幅が崩れる場合は，端末の「East Asian Ambiguous 文字の幅」を 1（半角）に設定してください．
