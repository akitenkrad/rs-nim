# Game records and replay

rs-nim can replay a game from a plain-text record file (`.nimrec`). Records can be written by hand, generated by another program, or saved from a game you played. Replay mode is also designed for screen recording: it plays back automatically at a fixed pace and can quit by itself at the end.

## Replaying a record

```sh
rs-nim replay examples/records/classic-1357.nimrec
```

| Option | Description |
|---|---|
| `<FILE>` | Record file, or `-` to read from standard input |
| `--interval <INTERVAL>` | Automatic playback interval in milliseconds (default `1500`; values below the 480 ms stone-removal animation are raised to 480) |
| `--paused` | Start playback paused |
| `--exit-on-end` | Exit three seconds after reaching a finished record's end |
| `--print` | Print the replay as text instead of starting the TUI |
| `--lang <LANG>` | Display language: `en` (default) or `ja`. Also applies to `--print` |

If the file cannot be read or contains an error, rs-nim prints the problem (with its line number) to standard error and exits with status 1 before the TUI starts.

### Controls in replay mode

| Key | Action |
|---|---|
| `Space` | Play / pause |
| `→` / `l` | Step forward one move (with animation) |
| `←` / `h` | Step back one move |
| `Home` / `g` | Jump to the start |
| `End` / `G` | Jump to the end |
| `+` / `-` | Faster / slower (250 ms per step) |
| `b` | Toggle the nim-sum panel |
| `q` / `Esc` / `Ctrl-C` | Quit |

The status bar shows whether playback is running, the move number (`k/N`) and the current interval. When the last move ends the game, the result panel announces the winner by name; a record that stops mid-game ends with "End of record" instead.

### Text output

`--print` checks the record and prints each move with the resulting heaps and nim-sum, which is handy for verifying a file or for scripting:

```sh
rs-nim replay examples/records/classic-1357.nimrec --print
```

```text
Move 1: Alice D 2
  Heaps: A=1 B=3 C=5 D=5
  Nim-sum: 2
  ...
```

## Saving your own games

During a game or on the result screen, press `s` to save the current game as `nim-<unix-seconds>.nimrec`. Files go to the current directory unless you start rs-nim with `--record-dir <DIR>`:

```sh
rs-nim --record-dir ~/nim-records
```

Saved records leave out the default names, so they are shown as You / CPU in English and あなた / CPU in Japanese. Add `human` / `cpu` lines to name the players.

## The `.nimrec` format

A record is UTF-8 text: a header of `key = value` lines followed by one move per line.

```text
# rs-nim record v1
rule  = normal     # normal | misere   (default: normal)
first = human      # human | cpu       (default: human)
heaps = 1 3 5 7    # required; separated by spaces or commas
human = Alice      # optional display name of the "human" side (default: You / あなた)
cpu   = Bob        # optional display name of the "cpu" side   (default: CPU)

D 2                # move: heap, then number of stones to take
B 2
c 3                # heap letters are case-insensitive
4 3                # heaps may also be numbered from 1 (4 = D)
```

Rules:

- `#` starts a comment; blank lines are ignored.
- Header keys may only appear before the first move. Unknown or duplicated keys are errors.
- `heaps` lists 1 to 6 heaps of 0 to 9 stones each, with at least one non-empty heap.
- `human` and `cpu` are just the two sides; in replay they are shown with the names you give them, so a record can describe any two players.
- Moves alternate starting with `first`. Each move must be legal: the heap must exist and you must take between 1 and the number of stones left.
- A move after the game has ended is an error. A record may stop before the game ends.

Three sample records live in [`examples/records/`](../examples/records/):

| File | Contents |
|---|---|
| `classic-1357.nimrec` | 1-3-5-7, normal rule; the second player keeps the nim-sum at 0 and wins |
| `misere.nimrec` | A short misère game |
| `unfinished.nimrec` | A record that stops mid-game |

## Recording a video

Replay mode makes a game reproducible, so you can record the same game as often as you like. Make sure the recording terminal is at least 90 × 26 cells.

With [asciinema](https://asciinema.org):

```sh
asciinema rec -c "rs-nim replay game.nimrec --exit-on-end" nim.cast
```

With [VHS](https://github.com/charmbracelet/vhs), a tape file such as:

```text
Output nim.gif
Set Width 1400
Set Height 700
Type "rs-nim replay game.nimrec --interval 1200 --exit-on-end"
Enter
Sleep 20s
```

`--exit-on-end` leaves the final position and result on screen for three seconds and then quits, so the recording ends cleanly. Use `--paused` instead if you want to step through the game by hand while recording.
